# Путеводитель по Ульяновску

Интерактивный веб-путеводитель по достопримечательностям, культурным местам, событиям и маршрутам Ульяновска.

Проект создан для того, чтобы помочь жителям и гостям города находить интересные места, знакомиться с историей Ульяновска и планировать самостоятельные прогулки.

## Живой сайт

Открыть опубликованную версию проекта можно по ссылке:

[Путеводитель по Ульяновску](https://1zenday1.github.io/putevoditel-ul)

## Рекомендуемый просмотр

Для наиболее точного отображения текущей версии макета рекомендуется использовать:

- разрешение viewport: **1920 × 1080**;
- масштаб браузера: **100%**;
- масштаб Windows: **100%**;
- обычный режим просмотра без включённого Device Toolbar.

Текущая версия проекта ориентирована на десктопный экран 1920 × 1080. Адаптивная версия для других размеров экранов находится в планах дальнейшей разработки.

## Статус
